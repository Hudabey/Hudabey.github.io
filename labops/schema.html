Implemented on MySQL 9.7.1 with full referential integrity. This very page carries the same schema in an embedded SQLite engine — the row counts below are being counted live, right now.

  1. PRIMARY KEY

    All nine tables; surrogate INT AUTO_INCREMENT; composite on run_claims doubles as M:N uniqueness.

  2. FOREIGN KEY ×9

    ON DELETE CASCADE from runs to metrics/checkpoints/run_claims; restrictive defaults protect master data — a node with runs cannot be deleted.

  3. UNIQUE

    researchers.email · projects.project_name · claims.claim_code · (run_id, metric_name).

  4. CHECK

    vram_gb > 0 · hourly_usd ≥ 0 · duration_min > 0 · size_gb > 0 — domain sanity at the engine level.

  5. NOT NULL · DEFAULT · ENUM

    Only notes and evidence_note are optional; safe defaults (status 'RUNNING', verdict 'OPEN'); closed vocabularies via the type system.

CREATE TABLE experiment_runs (
    run_id         INT           PRIMARY KEY AUTO_INCREMENT,
    project_id     INT           NOT NULL,
    node_id        INT           NOT NULL,
    researcher_id  INT           NOT NULL,
    run_label      VARCHAR(80)   NOT NULL,
    started_at     DATETIME      NOT NULL,
    duration_min   INT           NOT NULL,
    status         ENUM('GREEN','MIXED','FAILED','RUNNING')
                                 NOT NULL DEFAULT 'RUNNING',
    notes          VARCHAR(255),
    CONSTRAINT chk_duration CHECK (duration_min > 0),
    CONSTRAINT fk_runs_project    FOREIGN KEY (project_id)
        REFERENCES projects(project_id),
    CONSTRAINT fk_runs_node       FOREIGN KEY (node_id)
        REFERENCES gpu_nodes(node_id),
    CONSTRAINT fk_runs_researcher FOREIGN KEY (researcher_id)
        REFERENCES researchers(researcher_id)
);
